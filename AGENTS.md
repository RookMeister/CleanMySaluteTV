# AGENTS.md: установка CleanMySaluteTV на телевизор Sber

Ты ИИ-ассистент с доступом к терминалу. Владелец попросил поставить CleanMySaluteTV на свой Салют ТВ.
Работай на реальном ТВ по шагам и **проверяй каждое изменение скриншотом с ТВ** (`shot <имя>` из
`scripts/lib.sh`, файлы в `state/screens/`; посмотри на скриншот, прежде чем идти дальше). Всё, что
зависит от предпочтений владельца, спрашивай. Отвечай владельцу по-русски.

Сначала прочитай [docs/SBER.md](docs/SBER.md).

## 0. Что нужно на компьютере

`adb`, JDK 17, Android SDK 34 и `python3` (команды установки — в README). macOS: если `adb connect`
пишет «No route to host», хотя порт открыт, — это «Локальная сеть» в настройках конфиденциальности:
разреши её терминалу и перезапусти его.

## 1. Подготовка (спрашивай по одному пункту и жди «готово»)

1. ТВ и компьютер в одной сети Wi-Fi (не гостевая, VPN на компьютере на паузе).
2. Отладка по USB включена (docs/SBER.md, «Включить ADB»). Если меню разработчика не открывается,
   **не предлагай заводское меню без явного согласия владельца**: объясни риски из docs/SBER.md.
3. ТВ включён и стоит на главном экране, не на HDMI.
4. Предупреди: на ТВ появится «Разрешить отладку по USB?» — отметить «Всегда разрешать» и нажать OK.

## 2. Подключение

1. `bash scripts/find_tv.sh` или IP из настроек сети ТВ.
2. `cp cleanmysalutetv.conf.example cleanmysalutetv.conf`, впиши `TV_IP`.
3. `bash scripts/preflight.sh` — пройди с владельцем каждый ✗, пока всё не будет ✓.
4. `bash scripts/connect.sh`. Запиши в ответе модель, версию Android и плату (`getprop ro.board.platform`).

## 3. Бэкап — всегда до любых изменений

`bash scripts/backup.sh`.

## 4. Отключение лишнего (по желанию — спроси)

1. `bash scripts/inspect.sh` → `state/inspect/report.tsv`:
   - `disable` — безопасно отключать;
   - `ask` — стриминг, кастинг, сервисы Sber: **спроси одним списком, чем владелец пользуется**, отключай только остальное;
   - `keep` / `never` — не трогать; `profiles/never.txt` скрипты не дадут отключить;
   - `unknown` — никто не классифицировал: прочитай `state/inspect/unknown/<pkg>.txt`. Если есть
     обработчики кнопок пульта, входов, Bluetooth — оставь. Сомневаешься — спроси или оставь.
2. Согласованные пакеты — в `debloat-list.txt`, затем `bash scripts/debloat.sh debloat-list.txt`.
   После каждой пачки смотри скриншоты; если что-то сломалось — `adb shell pm enable --user 0 <pkg>` для этой пачки.
3. Ничего не удалять: только `pm disable-user`. Сервис Sber всё равно вернёт удалённое.
4. Новое о пакетах этой модели — дописать в `profiles/sber-staros.tsv`.

## 5. Настройки — спроси владельца

| `cleanmysalutetv.conf` | Вопрос |
|---|---|
| `DOCK` | Какие приложения в док и в каком порядке? (`adb shell pm list packages -3`) |
| `GREETING_NAME` | Имя в приветствии? |
| `COLUMNS_PER_ROW` | Сколько плиток в ряду (4–7)? |
| `WALLPAPER` | Свой JPEG или чёрный фон? |
| `SCREENSAVER` | `clock`, `original` или `off`? |
| `AD_BLOCK_DNS` | Включить DNS с блокировкой рекламы? После включения проверь, что видео в приложениях играет. |

## 6. Установка

`bash scripts/install.sh`. Он собирает APK, ставит его через `pm install -r`, пишет `config.json`
в папку лаунчера, запускает лаунчер и только после успешного запуска делает его Home. Штатный
`ru.sberdevices.starlauncher` по умолчанию не отключается.

## 7. Проверка (скриншот после каждого шага)

- Home: `key KEYCODE_HOME`, скриншот. Видны док и часы.
- Пульт: вверх, вниз, влево, вправо по плиткам; Back возвращает к доку.
- Входы: меню показывает HDMI, переключение работает (картинка HDMI на скриншоте чёрная — проверяй
  через `adb shell dumpsys tv_input | grep inputId`).
- Перезагрузка (`adb reboot`, только с согласия владельца): после неё Home всё ещё CleanMySaluteTV?
  Если нет — `DISABLE_STOCK_LAUNCHER=yes` и `bash scripts/install.sh --config-only`.
- Попроси владельца нажать настоящие кнопки Home, Input и Салют на пульте.

## 7а. Что показать владельцу

- Шестерёнка справа вверху — панель управления (Wi-Fi, Bluetooth, звук, изображение, память, входы).
- Удержать OK на шестерёнке → «Настройки главного экрана»: сцены, размер дока, погода (город ищется по
  названию), приложения. Изменения сделанные на ТВ главнее conf, пока не установлена новая тема.
- AirPlay — только если владелец хочет: docs/AIRPLAY.md. `AIRPLAY=yes` выдаёт лаунчеру `DUMP`:
  объясни, что это служебное разрешение, и спроси согласия.

## 8. Передача

Скажи, что отключено (`state/disabled_by_us.txt`), что `bash scripts/restore.sh` возвращает всё, что
настройки меняются через conf и `install.sh --config-only`, и **напомни выключить отладку по USB**.
