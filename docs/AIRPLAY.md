# AirPlay на Салют ТВ

Android TV сам не принимает AirPlay. Это делает отдельное бесплатное приложение
[AirPlay Server](https://github.com/jqssun/android-airplay-server) (`io.github.jqssun.airplay`, GPL-3.0):
после него телевизор виден на iPhone, iPad и Mac для повтора экрана, видео и звука.

После долгого сна приложение иногда продолжает работать, но перестаёт объявлять себя в сети, и
телевизор пропадает из списка AirPlay. CleanMySaluteTV за этим следит (идея и код — Hume Launcher):

- при пробуждении ТВ, при появлении сети и раз в 15 минут, пока открыт главный экран, лаунчер
  спрашивает сеть так же, как это делает Mac (запрос mDNS `_airplay._tcp`);
- если телевизор не ответил, приёмник незаметно перезапускается.

## Установка

1. Скачай APK из [релизов AirPlay Server](https://github.com/jqssun/android-airplay-server/releases)
   и поставь на ТВ: `adb install -r <файл>.apk`.
2. Открой AirPlay Server на ТВ, задай имя (например, «Салют ТВ») и включи **запуск при загрузке**:
   без него лаунчер не сможет поднять остановленный приёмник.
3. По желанию — полный перезапуск: в `cleanmysalutetv.conf` поставь `AIRPLAY=yes` и запусти
   `bash scripts/install.sh --config-only`.

## Два уровня перезапуска

| | Как | Что нужно |
|---|---|---|
| Только запуск | Сигнал «загрузка завершена» приложению: оно поднимает остановленный сервер | Ничего; в AirPlay Server включён запуск при загрузке |
| Полный | Через приёмник настроек приложения: сервер перезапускается и заново объявляет себя | Разрешение `DUMP`, его выдаёт `install.sh` при `AIRPLAY=yes` |

`DUMP` — служебное разрешение: оно даёт доступ к диагностическим дампам системы. Поэтому по
умолчанию оно не выдаётся, а `install.sh` без `AIRPLAY=yes` его отзывает.

## В меню

Настройки → Дополнительно → AIRPLAY: «Держать AirPlay видимым» (вкл/выкл), какой перезапуск доступен,
«Проверить сейчас». Пока AirPlay Server не установлен, там только подсказка.
