# Салют ТВ (Sber, StarOS)

Целевой телевизор: **Sber SDX-55UQ5231**. Он пока не подключался: плата, версия Android и список
пакетов станут известны после `bash scripts/connect.sh` и `bash scripts/inspect.sh`.

Всё ниже собрано по двум проверенным телевизорам Sber из [Gathin23/cleanyourtv](https://github.com/Gathin23/cleanyourtv)
(`examples/sber-salute-tv-pb766` и `examples/sber-salute-tv-at30a6`):

| | 32" pb766 | 43" at30a6 |
|---|---|---|
| Плата | CVTE, MediaTek MT9256, 1 ГБ | CVTE, Amlogic T962D4, 2 ГБ |
| Система | StarOS 1.103, Android 11 | StarOS 1.101, Android 13 |
| Меню разработчика | Открывается обычным способом | Заблокировано |
| Штатный лаунчер | Оставлен включённым | Отключён |

## Включить ADB

1. **Обычный способ.** Настройки → Настройки устройства → Об устройстве → 7 раз OK на «Сборка» →
   назад → Для разработчиков → Отладка по USB.
2. **Если меню разработчика не открывается.** На at30a6 помогло заводское меню CVTE: в нём есть
   переключатель Debug → ADB Enable. Ярлык к нему ставили из APK с 4PDA. Это сторонний файл и
   заводское меню с настройками панели — делай это только осознанно и ничего, кроме ADB Enable, там не трогай.
3. **Способ Sber** (developers.sber.ru → SmartApp → Мои устройства → ADB) на at30a6 не открыл порт 5555.

На части прошивок `ro.adb.secure=0`: окна «Разрешить отладку?» нет, и подключиться может любое
устройство в сети. **Выключай отладку после работы.**

## Что делает Sber после перезагрузки

`ru.sberdevices.services` считает часть приложений обязательными: переустанавливает их после удаления
и включает обратно после перезагрузки (Okko, СберПрайм, промо умного дома, «Настройка провайдеров»,
обновление пульта, бета, «Детская комната»). Поэтому:

- ничего не удаляем, только `pm disable-user`;
- то, что возвращается, прячем с главного экрана через `hidden_apps` (это делает `scripts/make_config.py`).

## Чего не трогать

`profiles/never.txt`: платформа Sber и ассистент, входы HDMI (`ru.sberdevices.tvinputs`,
`com.mediatek.tvinput`), клавиатура, WebView, `com.cvte.*`. Не открывай заводские приложения
`com.cvte.fac.menu`, `com.cvte.factory.*`, `com.cvte.tv.tools`, `ru.sberdevices.TvFactoryHelper`.

## Главный экран

Сначала `set-home-activity` без отключения штатного лаунчера (`DISABLE_STOCK_LAUNCHER=no`). На pb766
этого хватило, и после перезагрузки Home остался за новым лаунчером. Если Home открывает Салют ТВ,
поставь `DISABLE_STOCK_LAUNCHER=yes` и запусти `bash scripts/install.sh --config-only`.
